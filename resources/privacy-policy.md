# 淡香 プライバシーポリシー

最終更新日: 2026-09-04

淡香（以下「本アプリ」）は、Android アプリ「淡香」および本アプリの Hosted 機能を提供するサーバー（JournalingPostServer）に関する、利用者の情報の取り扱いについて定めます。

本アプリは、日記そのものを利用者の端末内に保存し、サーバーへ恒久的に保存しません。サーバーが扱うのは、利用者が明示的に依頼した AI 解析の処理に必要な範囲に限られます。

## 取得・処理する情報

### 端末内に保存される情報

- 日記の本文、気分の記録、作成日時
- AI による解析結果

これらは利用者の端末内にのみ保存されます。サーバーやその他の外部サービスへ、バックアップや同期の目的で送信することはありません。

### AI 解析のためにサーバーへ送信される情報

利用者が AI 解析を実行したとき、対象期間の日記の本文が本アプリのサーバーへ送信されます。サーバーはこの本文を解析のためだけに一時的に処理し、応答を返した後は恒久的に保存しません。

### サーバーが保持する情報

- 匿名の利用者識別子（アカウントや個人を特定しない、サーバー内部の識別子）
- Hosted 機能を利用するための API キーのハッシュ値（元の値は保存しません）
- 同じ解析依頼の重複実行を防ぐための短期的な管理情報
- 通信の切断時に同じ解析結果を返し直すための一時的な控え（解析の完了から 30 分で自動的に削除されます）

## 利用目的

- 利用者が依頼した日記の AI 解析を実行し、結果を返すため
- 同一の依頼が重複して処理されること、および重複した費用の発生を防ぐため
- 不正利用の防止およびサービスの安定運用のため

## 第三者への提供・外部サービスの利用

本アプリは、AI 解析の実行のために OpenAI, L.L.C. が提供する API を利用します。AI 解析を実行したとき、対象期間の日記の本文が解析処理のために OpenAI へ送信されます。

- 送信された内容は、OpenAI の API 利用規約上、既定では OpenAI のモデルの学習には使用されません。
- OpenAI 側では、不正利用の監視の目的で、送受信した内容が一定期間（標準では最大 30 日間）保持されることがあります。

上記および法令に基づく場合を除き、取得した情報を第三者へ提供することはありません。本アプリは、広告の配信、アクセス解析、位置情報の取得を行いません。

## 保管期間

- 端末内の日記および解析結果は、利用者が削除するまで端末内に保存されます。
- サーバーへ送信された日記の本文は、解析の応答を返した後は保持されません。通信の切断に備えた一時的な控えも、解析の完了から 30 分で自動的に削除されます。
- 匿名の利用者識別子および API キーのハッシュ値は、Hosted 機能の提供に必要な間、保持されます。

## 保持しない情報

本アプリのサーバーは、次の情報を取得・保持しません。

- 氏名、メールアドレス、電話番号、その他の連絡先
- 利用者のプロフィール、タイムゾーン、解析スケジュールの設定
- 端末の位置情報
- 広告識別子、プッシュ通知トークン

## 安全管理措置

- サーバーとの通信はすべて暗号化（HTTPS）されます。暗号化されていない通信は受け付けません。
- API キーはハッシュ化して保存し、元の値を保存・出力しません。
- 日記の本文を、通常のログや障害調査用の記録へ出力しません。

## 利用者の権利

- 端末内の日記および解析結果は、本アプリの操作でいつでも削除できます。
- 端末内のデータを削除し本アプリの利用を停止すると、以降サーバーへ情報が送信されることはありません。サーバー上の一時的な控えは、前述のとおり時間の経過により自動的に削除されます。

## お子様のプライバシー

本アプリは、13 歳未満の子どもを対象としていません。

## 本ポリシーの変更

本ポリシーは、法令の変更や本アプリの機能の変更に応じて改定されることがあります。重要な変更を行う場合は、本アプリまたは本ページ上で告知します。改定後のポリシーは、本ページに掲載した時点から効力を生じます。

## お問い合わせ

本ポリシーに関するお問い合わせは、本アプリの設定画面にあるフィードバック機能からご連絡ください。
